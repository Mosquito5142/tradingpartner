# ปฏิทินข่าวเทรดทอง (XAUUSD)

กดไฟล์เดียว → เปิดหน้าเว็บที่รวมกำหนดการข่าวเศรษฐกิจล่วงหน้า **เป็นเวลาไทย (GMT+7)**
พร้อมบอกว่าถ้าตัวเลขออกสูง/ต่ำกว่าที่ตลาดคาด ทองมักไปทางไหน

> ⚠️ เครื่องมือนี้รวบรวม **กำหนดการ + ความสัมพันธ์มหภาคแบบตำรา** เท่านั้น
> ไม่ใช่การทำนายราคาและไม่ใช่คำแนะนำการลงทุน ใช้ประกอบการตัดสินใจของตัวเอง

---

## วิธีใช้

ดับเบิลคลิก **`ดูข่าวทอง.bat`** — จบ

จะดึงข้อมูลล่าสุด สร้างไฟล์ `out/calendar.html` แล้วเปิดในเบราว์เซอร์ให้อัตโนมัติ

### ใช้ผ่าน command line (ถ้าต้องการ)

```bash
python gold_news.py                  # ค่าเริ่มต้น: ล่วงหน้า 14 วัน
python gold_news.py --days 30        # ดูล่วงหน้า 30 วัน
python gold_news.py --text           # พิมพ์ตารางลงหน้าจอด้วย
python gold_news.py --all            # รวมข่าวเล็กและข่าวขยะ (สต็อกน้ำมัน ฯลฯ)
python gold_news.py --no-open        # ไม่ต้องเปิดเบราว์เซอร์
python gold_news.py --back 0         # ไม่ต้องแสดงข่าวที่ผ่านไปแล้ว
python gold_news.py --no-chart       # ข้ามส่วนกราฟ (เร็วขึ้น)
python gold_news.py --lab            # ดูสถิติ Reaction Lab
python gold_news.py --backfill       # เก็บสถิติย้อนหลังแล้วออก
```

ใส่ flag ต่อท้าย `.bat` ก็ได้ เช่นสร้าง shortcut ที่ชี้ไป `ดูข่าวทอง.bat --days 30`

## หน้าเว็บมีอะไรบ้าง

| ส่วน | รายละเอียด |
|---|---|
| กล่องบนสุด | ข่าวใหญ่ตัวถัดไป + **นับถอยหลังสด** |
| ปุ่มกรอง | `เฉพาะข่าวใหญ่` / `ข่าวใหญ่ + ปานกลาง` / `ทั้งหมด` และกรองรายประเทศ |
| จุดสีหน้าเวลา | 🔴 แรง · 🟡 ปานกลาง · ⚫ เบา |
| คอลัมน์กลาง | ชื่อข่าวภาษาไทย + ชื่ออังกฤษ + ป้าย `⚡ ผันผวนแรง` |
| คอลัมน์ตัวเลข | คาดการณ์ / ครั้งก่อน / ผลจริง |
| คอลัมน์ขวาสุด | **ทิศทางทอง** — สูงกว่าคาด → ▲/▼ , ต่ำกว่าคาด → ▲/▼ |

ข่าวที่ไม่ใช่ตัวเลข (FOMC, แถลงของเฟด/ECB) จะขึ้นเป็น **โทนผ่อนคลาย → ทองขึ้น / โทนเข้มงวด → ทองลง**
เพราะต้องฟังเนื้อหาการแถลงเอง

## ส่วน "แผนวันนี้" (กราฟ 15 นาที + เวลา + แนวรับแนวต้าน)

อยู่บนสุดของหน้า มี 3 ส่วน:

**1. กราฟแท่งเทียน 15 นาที** — 24 ชั่วโมงล่าสุด วาดเส้นแนวรับ (เขียว) แนวต้าน (แดง)
และหมุดเวลาข่าวของวันนี้ (เส้นฟ้าแนวตั้ง) เป็น SVG ล้วน ไม่โหลดไลบรารีจากเน็ต

**2. วันนี้น่าเล่นกี่โมง** — แถบ 24 ช่อง ยิ่งเขียวเข้มยิ่งเป็นชั่วโมงที่ทองแกว่งแรง
คำนวณจาก **ช่วง High-Low มัธยฐานของแท่ง 15 นาที ย้อนหลัง 60 วัน** แยกตามชั่วโมงไทย
แล้วบวกน้ำหนักข่าวของวันนั้นเข้าไป · จุดฟ้า = ชั่วโมงนั้นมีข่าว

ผลที่ได้ตรงกับความจริงของตลาด — ชั่วโมงที่แกว่งแรงสุดคือ 20:00-22:00 น. (นิวยอร์กเปิด
ทับกับลอนดอน) รองมาคือ 19:00 น. (เวลาข่าวสหรัฐฯ) และ 04:00 น. เงียบที่สุดเพราะ CME ปิดพัก

**3. แนวรับ / แนวต้าน** — รวม 4 วิธีมาตรฐานเข้าด้วยกันแล้วจัดอันดับตามน้ำหนัก:

| วิธี | คำอธิบาย |
|---|---|
| โซนกลับตัว | จุด swing high/low แบบ fractal (3 แท่งซ้ายขวา) ย้อนหลัง 10 วัน จับกลุ่มเป็นโซน ยิ่งถูกแตะบ่อยยิ่งหนัก |
| Pivot รายวัน | PP / R1 / R2 / S1 / S2 จาก High-Low-Close ของเมื่อวาน |
| กรอบเมื่อวาน / เอเชีย | High-Low เมื่อวาน และกรอบช่วง 06:00-14:00 น. ของวันนี้ |
| เลขกลม | ทุก $25 |

โซนที่เพิ่งถูกแตะภายใน 2 วันได้น้ำหนักคูณสอง และระดับที่มาจากหลายวิธีทับกันจะถูกรวมเป็นตัวเดียว

### เรื่องราคาที่ต้องรู้

ทองล่วงหน้า COMEX (GC=F) **แพงกว่า spot ประมาณ $35** ถ้าเอามาคำนวณตรง ๆ เส้นจะเพี้ยนทั้งกระดาน
โปรแกรมจึงใช้ **PAXG** (โทเคนทองคำ ห่าง spot ~$5) เป็นแท่งเทียน แล้วปรับฐานด้วยราคา spot จริง

ถ้ากราฟโบรกเกอร์คุณยังไม่ตรง ให้ตั้ง `broker_offset` ใน `config.json`:

```
broker_offset = ราคาที่กราฟโบรกฯ แสดง − ราคา spot ที่หัวหน้าเว็บแสดง
```

## Reaction Lab — "ทฤษฎีว่าอย่างนี้ ของจริงเป็นแบบนี้"

กฎทิศทางใน `bias.py` มาจากตำรา ไม่เคยถูกตรวจสอบ โปรแกรมจึงวัดให้เองจากราคาจริง
แล้วเก็บสะสมไว้ที่ `data/reactions.json` ทุกครั้งที่รัน

```bash
python gold_news.py --backfill   # เก็บย้อนหลังเท่าที่แหล่งข้อมูลมี แล้วออก
python gold_news.py --lab        # ดูสถิติที่สะสมไว้
```

**ผลที่วัดได้ (ข่าวใหญ่สหรัฐฯ n=35):**

| หลังข่าว | ทฤษฎีถูก | ขยับมัธยฐาน |
|---|---|---|
| 5 นาที | 66% | $6.60 |
| **10–15 นาที** | **71%** | **$8.90** |
| 30 นาที | 51% | $8.00 |
| 60 นาที | 49% | $13.90 |

**กฎใช้ได้จริง แต่มีอายุราว 15 นาที** หลัง 30 นาทีความแม่นตกเหลือ ~50% เท่ากับเดาสุ่ม
ตรวจแล้วว่าไม่ใช่ผลของเทรนด์ขาขึ้น (เส้นฐาน = ทองปิดบวก 51.2% ของทุกชั่วโมง หลังข่าว 54%)

**แยกตามกลุ่มข่าว — ต้องดู % ถูก คู่กับระยะที่ขยับเสมอ:**

| กลุ่ม | n | 15 นาที ถูก | ขยับมัธยฐาน |
|---|---|---|---|
| ข่าวใหญ่สหรัฐฯ | 35 | 71% | $8.90 |
| ข่าวกลางสหรัฐฯ | 62 | 52% | $6.90 |
| ยุโรป / จีน | 33 | 73% | $4.40 |

ยุโรป/จีนแม่นสูงแต่ขยับแค่ $4 ซึ่งเกือบเท่าสเปรด — **ความแม่นที่ขยับน้อยกินไม่ได้จริง**

### ทำไมต้องเก็บสะสมเอง
Yahoo ให้แท่ง 5 นาทีย้อนหลังแค่ 60 วัน แยกรายข่าวแล้วเหลือกลุ่มละ 2-3 ตัวอย่าง
โปรแกรมจึงบันทึกทุกครั้งที่รันและ**ไม่เคยลบของเก่า** ยิ่งใช้นานสถิติรายข่าวยิ่งเชื่อถือได้
(ตัวอย่างน้อยกว่า 3 ครั้งจะไม่แสดง % เลย เขียนว่า "ตัวอย่างยังน้อยเกินสรุป" แทน)

## เครื่องคำนวณขนาดล็อต (รองรับบัญชี Cent)

อยู่ท้ายส่วน "แผนวันนี้" คำนวณสองทาง: จาก %เสี่ยง → ขนาดล็อต และจากล็อต → %เสี่ยง

```
กำไร/ขาดทุน (หน่วยบัญชี) = ระยะราคา($) × ล็อต × 100
ขนาดล็อต = (ยอดเงิน × %เสี่ยง) / (ระยะ SL × 100)
```

บัญชี Cent ยอดเงินเป็น USC และ P&L ก็เป็น USC → คณิต %เสี่ยงเหมือนบัญชีปกติทุกประการ
ต่างแค่มูลค่าเงินจริง = USC ÷ 100 วิดเจ็ตแสดงทั้งสองหน่วยกันสับสน

จะเตือนให้อัตโนมัติเมื่อ SL แคบกว่าระยะแกว่งปกติช่วงข่าว ($8.90 ใน 15 นาที จาก Reaction Lab)
หรือเมื่อไม้เดียวกินพอร์ตเกิน 10% — เป็นการบอกข้อเท็จจริง ไม่ใช่สั่งว่าควรทำอะไร

ตั้งค่าเริ่มต้นได้ใน `config.json` (`account_type`, `account_balance`, `risk_percent`)

## หลักคิดเบื้องหลังคอลัมน์ "ทิศทางทอง"

ทองไม่มีดอกเบี้ย จึงอ่อนไหวกับ **ดอกเบี้ยแท้จริงและค่าเงินดอลลาร์**

```
เศรษฐกิจสหรัฐฯ ร้อน / เงินเฟ้อสูง  → เฟดคงดอกเบี้ยสูงนาน → ดอลลาร์+ยิลด์ขึ้น → ทองมักลง
เศรษฐกิจสหรัฐฯ อ่อน / เงินเฟ้อต่ำ  → ตลาดคาดเฟดลดดอกเบี้ย → ดอลลาร์อ่อน    → ทองมักขึ้น
```

ข้อยกเว้นที่ใส่ไว้ในกฎแล้ว:

- **อัตราการว่างงาน / ยอดขอรับสวัสดิการว่างงาน** — ยิ่งสูงยิ่งแย่ ⇒ ทองมัก **ขึ้น**
- **ยุโรป** — ยุโรปแข็ง ⇒ ยูโรแข็ง ⇒ ดัชนีดอลลาร์อ่อน ⇒ หนุนทองทางอ้อม
- **จีน** — จีนคือผู้บริโภคทองรายใหญ่สุด เศรษฐกิจจีนดี ⇒ ดีมานด์ทองจริงเพิ่ม ⇒ บวกต่อทองอ่อน ๆ

แก้กฎได้ที่ [goldnews/bias.py](goldnews/bias.py) และแก้คำแปลชื่อข่าวที่ [goldnews/translate.py](goldnews/translate.py)

## แหล่งข้อมูล

**ปฏิทินข่าว**
1. **TradingView Economic Calendar** (หลัก) — ฟรี ไม่ต้องใช้ API key ดึงล่วงหน้าได้หลายเดือน
2. **ForexFactory / FairEconomy** (สำรอง) — ใช้เมื่อแหล่งแรกล่ม ได้เฉพาะสัปดาห์ปัจจุบัน
3. **`cache/events.json`** (สำรองสุดท้าย) — ถ้าเน็ตหลุด จะใช้ข้อมูลครั้งล่าสุดพร้อมขึ้นแบนเนอร์เตือน

**ราคา**
1. **gold-api.com** — ราคา spot XAU ปัจจุบัน (ใช้ปรับฐาน)
2. **Binance PAXGUSDT** — แท่งเทียน 15 นาที ~10 วัน (ใช้หาแนวรับแนวต้าน)
3. **Yahoo Finance GC=F** — แท่ง 15 นาที 60 วัน (โปรไฟล์รายชั่วโมง) และ 5 นาที 60 วัน (Reaction Lab)
4. **`cache/price.json`** (สำรอง)

ทุกแหล่งฟรีและไม่ต้องใช้ API key · แท่งเสาร์-อาทิตย์ของ PAXG ถูกตัดทิ้งเพราะตลาดทองจริงปิด

> เวลาประกาศอาจถูกเลื่อนโดยหน่วยงานต้นทาง ควรกดรีเฟรชอีกครั้งก่อนเข้าเทรดจริง

## โครงสร้างโปรเจกต์

```
ดูข่าวทอง.bat          ← ดับเบิลคลิกไฟล์นี้
gold_news.py            ← entry point + CLI
config.json             ← ตั้งค่า
goldnews/
  fetch.py              ← ดึงปฏิทินข่าว + แปลงเป็นเวลาไทย + cache/fallback
  bias.py               ← กฎทิศทางทอง
  translate.py          ← คำแปลชื่อข่าว + ตัวกรองข่าวขยะ
  price.py              ← ดึงราคา 15 นาที + ปรับฐานให้ตรงโบรกเกอร์
  levels.py             ← คำนวณแนวรับ/แนวต้าน
  hours.py              ← โปรไฟล์ความผันผวนรายชั่วโมง + ช่วงน่าจับตาวันนี้
  chart.py              ← กราฟแท่งเทียน SVG
  reactions.py          ← Reaction Lab: วัด/เก็บ/สรุปปฏิกิริยาข่าว
  briefing.py           ← ประกอบการ์ดสรุปก่อนข่าว (คืน dict ใช้ต่อได้)
  briefing_view.py      ← แปลงการ์ดเป็น HTML
  plan_view.py          ← ส่วน "แผนวันนี้" + เครื่องคำนวณล็อต
  render.py             ← ประกอบหน้าเว็บทั้งหมด
data/                   ← คลังสถิติที่สะสม (เก็บไว้ ห้ามลบ)
cache/  out/            ← ไฟล์ที่โปรแกรมสร้างเอง (สร้างใหม่ได้)
```

ใช้ Python standard library ล้วน — ไม่ต้อง `pip install` อะไรเลย (ต้องมี Python 3.9+)
